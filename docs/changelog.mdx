## Unreleased

### New

- Rebranded the browser, desktop, CLI, signaling server, containers, installers, documentation, and release automation as Rilldrop.
- Added a stream-in-a-drop identity with regenerated web, Windows, PWA, favicon, Store-package, and social assets.
- Moved package coordinates and release links to `Arnavsharma2/rilldrop`.
- Made local and self-hosted endpoints the explicit defaults instead of claiming an official hosted service.
- Added clearer semantics for transfer progress, file lists, and icon-only controls.

### Changed

- Reset the desktop version line to `0.1.0` for the standalone Rilldrop project.
- Removed inherited screenshots and distribution claims that do not describe a published Rilldrop release.
- Kept the existing WebRTC transfer protocol compatible across the browser, desktop, and CLI implementations.

## Source import

Rilldrop began from the source of [Floe](https://github.com/jannskiee/floe) at upstream commit [`6d1e629`](https://github.com/jannskiee/floe/commit/6d1e629). Floe was created by [Jan Carlo Paredes (@jannskiee)](https://github.com/jannskiee) and released under the MIT License.

The upstream commit history is intentionally not reproduced in this repository. The source-import commit preserves the original copyright and license, and all later commits track Rilldrop-specific work.

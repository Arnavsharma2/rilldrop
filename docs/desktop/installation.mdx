Rilldrop Desktop is currently a development build for 64-bit Windows 10 version 2004 or later. It requires the Microsoft WebView2 runtime included with current Windows installations.

## GitHub release

When a `desktop-vX.Y.Z` release is published, it contains:

- `rilldrop-desktop-setup-X.Y.Z.exe`: per-user installer
- `rilldrop-desktop-X.Y.Z-windows-amd64.zip`: portable executable
- `SHA256SUMS.txt`: checksums for both artifacts

Browse [Rilldrop releases](https://github.com/Arnavsharma2/rilldrop/releases). Rilldrop does not currently claim an official app-store listing.

Unsigned development builds may trigger Windows SmartScreen. Verify the checksum against `SHA256SUMS.txt` before running a downloaded artifact.

## Build from source

Install Go 1.25, Node.js, and the Wails v2 CLI, then run:

```powershell
cd desktop\frontend
npm ci
npm test
npm run build

cd ..
go test ./...
wails build
```

The executable is written to `desktop\build\bin\rilldrop-desktop.exe`.

## Uninstall

The installer creates a per-user installation. Use Windows **Installed apps** to remove it. The portable ZIP can be removed by deleting its folder.

Settings and transfer history live under the user configuration directory in `rilldrop`. Remove that directory separately if you also want to erase local preferences and history.

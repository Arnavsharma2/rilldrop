```bash rilldrop version
rilldrop version
```

Prints the current version of the `rilldrop` binary, a link to the documentation, and an update
hint when a newer release is available.

## Output

```text Output
rilldrop 1.x.x
Docs: https://github.com/Arnavsharma2/rilldrop/tree/main/docs
```

When a newer release exists, a third line follows:

```text Output
Update available: v1.x.x  run `rilldrop update` to upgrade
```

## The update check

`rilldrop version` is the only command that checks for a newer release on its own. `send` and
`receive` never do, and `rilldrop update` checks only when you run it. The check asks GitHub for
the latest release tag (`https://api.github.com/repos/Arnavsharma2/rilldrop/releases/latest`) and
caches the answer for 24 hours in `rilldrop/update-check.json` inside your user config directory
(`~/.config` on Linux, `~/Library/Application Support` on macOS, `%AppData%` on Windows).
Delete that file to force a fresh check. When the cache is cold, the request is abandoned
after one second, so `rilldrop version` never stalls on a slow network.

Set `RILLDROP_NO_UPDATE_CHECK=1` to skip the check and the hint entirely. Binaries built from
source report `rilldrop dev` and never check.

## Alternatives

You can also use the root flag:

```bash Terminal
rilldrop --version
# or
rilldrop -v
```

These print the same single line as the first line of `rilldrop version` (for example
`rilldrop 1.x.x`). No docs link, and no update hint.

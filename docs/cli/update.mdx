---
title: "Update the Rilldrop CLI"
sidebarTitle: "Update"
description: "Check for and install a newer rilldrop CLI release from GitHub."
---

Release builds can update themselves from the standalone repository:

```bash Terminal
rilldrop update --check
rilldrop update
```

`--check` reports whether a newer `vX.Y.Z` release exists without downloading anything. `rilldrop update` downloads the archive for your operating system and architecture, verifies the release checksum, and replaces the current executable.

Development builds report version `dev` and cannot self-update. Rebuild them from source instead:

```bash Terminal
git pull
go build -o rilldrop ./cli/cmd/rilldrop
```

Set `RILLDROP_NO_UPDATE_CHECK=1` to disable the optional check performed by `rilldrop version`. Explicit `rilldrop update` commands still contact GitHub because the command itself requests that operation.

Release assets are published at [github.com/Arnavsharma2/rilldrop/releases](https://github.com/Arnavsharma2/rilldrop/releases).

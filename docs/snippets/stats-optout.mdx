Every receiving surface can turn the report off, and turning it off means the byte count is never
sent, rather than sent and ignored.

- **Browser:** uncheck **Contribute to global stats** on the receiver view before the first file
  lands. The choice is saved in that browser and applies to every later transfer from it.
- **Rilldrop Desktop:** turn off **Contribute to global stats** in
  [Settings](/desktop/settings#contribute-to-global-stats). It is saved with your other settings.
- **CLI:** pass `--no-report` to `rilldrop receive` for one transfer, or set `RILLDROP_NO_STATS=1` in your
  environment to opt out for good.

The sender never reports on any surface, so this only ever concerns transfers you receive.

This switch covers the public counter and nothing else. A deployment operator can separately enable
anonymous web analytics, described under [Error monitoring and analytics](/security-privacy#error-monitoring-and-analytics).
The CLI, desktop app, and any web instance without an analytics key send no analytics.
